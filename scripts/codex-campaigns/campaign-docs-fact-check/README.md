# Campaign — Docs Fact-Check

Adversarial fact-check of every consumer-facing HELiX documentation file
against the actual source code in this monorepo. Zero fabrications. Zero
trust.

## Scope

181 target files:

- `apps/docs/src/content/docs/**/*.{md,mdx}` — 135 files
- `apps/storybook/stories/**/*.mdx` — 29 files
- `packages/*/README.md` — 6 files
- `packages/*/CHANGELOG.md` — 8 files
- `README.md`, `CONTRIBUTING.md`, `CLAUDE.md` (root) — 3 files

## Why

Phase 1–H of the docs cleanup epic shipped the structural cleanup
(deletes, sidebar, version drift gate). This campaign goes the next layer:
**every claim in every surviving doc is verified against source.**

## Prompt placeholders

The campaign runner substitutes `{TARGET}` with the relative path to each
target file before invoking Codex. The prompt itself contains the full
fact-check directives — see `prompt.md`.

## Output

- `.reports/codex/campaigns/docs-fact-check/findings.jsonl` — appended
  per-finding stream.
- `.reports/codex/campaigns/docs-fact-check/transcripts/<slug>.log` — full
  Codex transcript per target.
- `.reports/codex/campaigns/docs-fact-check/findings.md` — consolidated
  rollup (generated by `consolidate-findings.ts`).
- `.reports/codex/campaigns/docs-fact-check/scoreboard.json` — per-file
  verdict counts (generated).

## How to run

```bash
# Pilot — first 10 files for harness shakeout
/codex-campaign docs-fact-check --limit 10

# Full sweep — all 181 files (~3–4 hours of Codex time)
/codex-campaign docs-fact-check
```

## Budget guard

At ~$0.02–0.05 per file × 181 files = $4–9 in Codex cost. Well under the
$30–50 ceiling. If a target exceeds 30 minutes, investigate before
continuing.
