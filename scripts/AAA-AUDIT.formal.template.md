## Re-certification triggers

This certification is invalidated and a re-run of `scripts/aaa-formal-audit.mjs` is required when ANY of the following occur:

- The component's class file (`{{sourceClassPath}}`) or styles file (`{{sourceStylesPath}}`) is modified.
- A semantic token consumed by the component (`--hx-color-*`, `--hx-focus-ring-*`, `--hx-touch-target-*`, etc.) changes value or fallback.
- The component's `@aria-pattern` JSDoc tag changes.
- The component's `@keyboard-contract` JSDoc tag changes.
- The component's `@form-associated` JSDoc tag changes.
- The Default Storybook story is restructured such that the audited surface changes.
- WCAG 2.2 is superseded by a later Recommendation, or `aaa-standards.json` is regenerated against a newer source.
- A criterion's verdict regresses from Supports to Partially Supports or Does Not Support in any subsequent harness run.

The `aaa-cert.mjs` gate enforces that the per-component evidence file is fresher than the source files; CI fails if drift is detected.
