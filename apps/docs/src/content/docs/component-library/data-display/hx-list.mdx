## Overview

`hx-list` is a styled list container that accepts `hx-list-item` elements. It supports five visual variants: `plain`, `bulleted`, `numbered`, `description` (term/definition pairs), and `interactive` (a selectable listbox). Dividers can be enabled between items for any variant.

**Use `hx-list` when:** you need to present structured content — medication lists, procedure checklists, patient navigation menus, or filterable item selections.

**Use `hx-list` with `variant="interactive"` when:** you need a keyboard-navigable single-select list (listbox pattern) without a dropdown — sidebar category filters, option panels.

## Installation

```bash
# Full library
npm install @helixui/library

```

## Basic Usage

```html
<!-- Simple bulleted list -->
<hx-list variant="bulleted">
  <hx-list-item>Item one</hx-list-item>
  <hx-list-item>Item two</hx-list-item>
</hx-list>

<!-- Interactive selection list -->
<hx-list variant="interactive" label="Select a department">
  <hx-list-item value="cardiology">Cardiology</hx-list-item>
  <hx-list-item value="neurology">Neurology</hx-list-item>
</hx-list>
```

## Properties

| Property  | Attribute | Type                                                                    | Default     | Description                                                                                           |
| --------- | --------- | ----------------------------------------------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------- |
| `variant` | `variant` | `'plain' \| 'bulleted' \| 'numbered' \| 'description' \| 'interactive'` | `'plain'`   | Visual variant. `interactive` enables listbox selection behavior.                                     |
| `divided` | `divided` | `boolean`                                                               | `false`     | Whether to show dividers between list items.                                                          |
| `label`   | `label`   | `string`                                                                | `undefined` | Accessible label for the list. **Required when `variant="interactive"`** (WCAG 4.1.2 — listbox name). |

## Events

| Event       | Detail                                                | Description                                               |
| ----------- | ----------------------------------------------------- | --------------------------------------------------------- |
| `hx-select` | `{ item: HelixListItem, value: string \| undefined }` | Dispatched when an item is clicked in `interactive` mode. |

## CSS Custom Properties

| Property                  | Default                       | Description             |
| ------------------------- | ----------------------------- | ----------------------- |
| `--hx-list-gap`           | `0`                           | Gap between list items. |
| `--hx-list-divider-color` | `var(--hx-color-neutral-200)` | Divider line color.     |

## Accessibility

| Topic         | Details                                                                                                                                                                                                               |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Roles         | `plain`, `bulleted`, `numbered`: uses `role="list"` (or `<dl>` for `description`). `interactive`: uses `role="listbox"` with `aria-multiselectable="false"`.                                                          |
| `aria-label`  | When `variant="interactive"`, the `label` property is applied as `aria-label` on the listbox. **Always provide a label in interactive mode** — a missing label is a WCAG 4.1.2 violation and emits a console warning. |
| Keyboard      | In `interactive` mode: `Arrow Down` / `Arrow Up` move focus between items, `Home` jumps to the first item, `End` to the last. Focus wraps at both ends.                                                               |
| Screen reader | In interactive mode, the listbox role signals to AT that items are selectable options. Each `hx-list-item[value]` should have meaningful text content as its label.                                                   |

## Drupal Integration

```twig
{# my-module/templates/item-list.html.twig #}
<hx-list
  variant="{{ variant|default('plain') }}"
  {% if divided %}divided{% endif %}
  {% if label %}label="{{ label }}"{% endif %}
>
  {% for item in items %}
    <hx-list-item{% if item.value %} value="{{ item.value }}"{% endif %}>
      {{ item.label }}
    </hx-list-item>
  {% endfor %}
</hx-list>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```

## Standalone HTML Example

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>hx-list example</title>
    <!-- @helixui/library is a private package — install via npm workspace, not CDN -->
    <!-- In your project: import '@helixui/library'; in your bundler entry point -->
  </head>
  <body style="font-family: sans-serif; padding: 2rem; max-width: 480px; margin: 0 auto;">
    <h2>Current Medications</h2>
    <hx-list variant="bulleted" divided>
      <hx-list-item>Metformin 500mg — twice daily</hx-list-item>
      <hx-list-item>Lisinopril 10mg — once daily</hx-list-item>
      <hx-list-item>Atorvastatin 20mg — once daily at bedtime</hx-list-item>
    </hx-list>

    <h2>Filter by Department</h2>
    <hx-list variant="interactive" label="Filter by department" divided id="dept-list">
      <hx-list-item value="cardiology">Cardiology</hx-list-item>
      <hx-list-item value="internal-medicine">Internal Medicine</hx-list-item>
      <hx-list-item value="orthopedics">Orthopedics</hx-list-item>
      <hx-list-item value="neurology">Neurology</hx-list-item>
    </hx-list>

    <script>
      document.getElementById('dept-list').addEventListener('hx-select', (e) => {
        console.log('Selected:', e.detail.value);
      });
    </script>
  </body>
</html>
```
