## Overview

`hx-rating` is a star rating input component supporting whole-star and half-star precision. It participates in native HTML forms via `ElementInternals`, includes keyboard navigation, hover preview, and read-only display mode. The ARIA pattern adapts automatically — `role="radiogroup"` for whole-star ratings, `role="slider"` for half-star, and `role="img"` for read-only display.

**Use `hx-rating` when:** collecting or displaying patient satisfaction scores, quality ratings, appointment feedback, or provider evaluations.

## Basic Usage

```html
<!-- Interactive rating input -->
<hx-rating name="satisfaction" label="Rate your visit" max="5"></hx-rating>

<!-- Half-star precision -->
<hx-rating value="3.5" max="5" precision="0.5" label="Experience rating"></hx-rating>

<!-- Read-only display -->
<hx-rating value="4" max="5" readonly label="Provider rating"></hx-rating>
```

## Properties

| Property         | Attribute         | Type                                     | Default                        | Description                                                                      |
| ---------------- | ----------------- | ---------------------------------------- | ------------------------------ | -------------------------------------------------------------------------------- |
| `value`          | `value`           | `number`                                 | `0`                            | The current rating value (0 to `max`).                                           |
| `max`            | `max`             | `number`                                 | `5`                            | The maximum number of stars.                                                     |
| `precision`      | `precision`       | `0.5 \| 1`                               | `1`                            | Minimum selectable increment. Use `0.5` for half-star ratings.                   |
| `readonly`       | `readonly`        | `boolean`                                | `false`                        | When true, the rating is display-only and cannot be changed. Uses `role="img"`.  |
| `disabled`       | `disabled`        | `boolean`                                | `false`                        | When true, the rating is disabled and cannot be interacted with.                 |
| `name`           | `name`            | `string`                                 | `''`                           | The name submitted with the parent form (`<input name="...">` equivalent).       |
| `label`          | `label`           | `string`                                 | `''`                           | Accessible label for the rating group. Falls back to `'Rating'` if not provided. |
| `required`       | `required`        | `boolean`                                | `false`                        | When true, a non-zero rating is required for form submission.                    |
| `labelStar`      | _(property only)_ | `(count: number) => string`              | `(n) => "1 star" / "N stars"`  | Generates accessible labels for individual star elements. Override for i18n.     |
| `labelValueText` | _(property only)_ | `(value: number, max: number) => string` | `(v, m) => "v out of m stars"` | Generates the `aria-valuetext` for the slider widget. Override for i18n.         |

## Events

| Event       | Detail              | Description                                          |
| ----------- | ------------------- | ---------------------------------------------------- |
| `hx-change` | `{ value: number }` | Dispatched when the rating value changes.            |
| `hx-hover`  | `{ value: number }` | Dispatched while hovering over a star for a preview. |

## Accessibility

| Topic                       | Details                                                                                                                                                                                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Interactive (precision=1)   | Uses `role="radiogroup"` with individual `role="radio"` star elements. Each star has `aria-label` ("1 star", "2 stars") and `aria-checked`. Follows the WAI-ARIA Radio Group pattern.                                                                   |
| Interactive (precision=0.5) | Uses `role="slider"` with `aria-valuemin`, `aria-valuemax`, `aria-valuenow`, and `aria-valuetext` (e.g., "2.5 out of 5 stars"). Avoids WCAG 2.5.3 label-content-name mismatch that would occur if a radio labeled "3 stars" represented a value of 2.5. |
| Read-only                   | Uses `role="img"` with `aria-label` combining the `label` property and the value text (e.g., "Provider rating: 4 out of 5 stars").                                                                                                                      |
| Keyboard                    | Arrow keys (Left/Right or Up/Down) adjust the value by one `precision` step. `Home` sets value to 0, `End` sets to `max`.                                                                                                                               |
| Disabled                    | Sets `aria-disabled="true"` on the container and `tabindex="-1"` to remove keyboard focus.                                                                                                                                                              |
| Form                        | Participates in native HTML forms via `ElementInternals`. Supports `name`, `required`, `checkValidity()`, `reportValidity()`, and `formResetCallback`.                                                                                                  |

## Drupal Integration

```twig
{# my-module/templates/patient-feedback.html.twig #}
<hx-rating
  name="{{ field_name }}"
  label="{{ label }}"
  value="{{ value|default(0) }}"
  max="{{ max|default(5) }}"
  {% if readonly %}readonly{% endif %}
  {% if required %}required{% endif %}
></hx-rating>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```

## Standalone HTML Example

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>hx-rating example</title>
    <!-- @helixui/library is a private package — install via npm workspace, not CDN -->
    <!-- In your project: import '@helixui/library'; in your bundler entry point -->
  </head>
  <body style="font-family: sans-serif; padding: 2rem; max-width: 480px;">
    <h2>Patient Satisfaction Survey</h2>

    <form id="feedback-form">
      <div style="margin-bottom: 1.5rem;">
        <label style="display: block; margin-bottom: 0.5rem; font-weight: 600;"
          >Overall Experience</label
        >
        <hx-rating name="overall" label="Overall experience rating" max="5" required></hx-rating>
      </div>
      <div style="margin-bottom: 1.5rem;">
        <label style="display: block; margin-bottom: 0.5rem; font-weight: 600;">Wait Time</label>
        <hx-rating name="wait-time" label="Wait time rating" max="5" precision="0.5"></hx-rating>
      </div>
      <button type="submit">Submit Feedback</button>
    </form>

    <h2>Provider Ratings (Read-Only)</h2>
    <div style="display: flex; flex-direction: column; gap: 0.5rem;">
      <hx-rating value="4.5" max="5" precision="0.5" readonly label="Dr. Chen"></hx-rating>
      <hx-rating value="5" max="5" readonly label="Dr. Patel"></hx-rating>
    </div>

    <script>
      document.getElementById('feedback-form').addEventListener('submit', (e) => {
        e.preventDefault();
        const data = new FormData(e.target);
        console.log('Overall:', data.get('overall'));
        console.log('Wait Time:', data.get('wait-time'));
      });

      document.querySelectorAll('hx-rating:not([readonly])').forEach((el) => {
        el.addEventListener('hx-change', (e) => {
          console.log('Rating changed to:', e.detail.value);
        });
      });
    </script>
  </body>
</html>
```
