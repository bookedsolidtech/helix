## Overview

`hx-stat` is a compact metric display component. It renders a prominent `value` with a descriptive `label` below it, an optional trend indicator (`up`, `down`, `neutral`), and an optional icon slot alongside the value.

**Use `hx-stat` when:** you need a labeled, contextualized metric — beds occupied, patient wait time, appointment count — especially in dashboards where trend direction matters.

**Use `hx-counter` instead when:** you only need an animated number without a label or trend indicator.

```html

```

## Properties

| Property | Attribute | Type                          | Default     | Description                                               |
| -------- | --------- | ----------------------------- | ----------- | --------------------------------------------------------- |
| `value`  | `value`   | `string`                      | `''`        | The metric value displayed prominently.                   |
| `label`  | `label`   | `string`                      | `''`        | The metric label displayed below the value.               |
| `trend`  | `trend`   | `'up' \| 'down' \| 'neutral'` | `'neutral'` | Trend direction indicator. `neutral` hides the indicator. |
| `size`   | `hx-size` | `'sm' \| 'md' \| 'lg'`        | `'md'`      | Size variant controlling font size.                       |

## Events

`hx-stat` does not dispatch any custom events.

## CSS Parts

| Part        | Description                                                              |
| ----------- | ------------------------------------------------------------------------ |
| `container` | The outer stat container element.                                        |
| `header`    | The row containing the value and optional icon.                          |
| `value`     | The stat value element.                                                  |
| `label`     | The stat label element.                                                  |
| `trend`     | The trend indicator element (only rendered when trend is not `neutral`). |
| `icon`      | The icon slot container.                                                 |

## Slots

| Slot   | Description                                  |
| ------ | -------------------------------------------- |
| `icon` | Optional icon displayed alongside the value. |

## Accessibility

| Topic         | Details                                                                                                                     |
| ------------- | --------------------------------------------------------------------------------------------------------------------------- |
| ARIA role     | The stat container uses `role="group"` with an `aria-label` combining the value and label for grouped metric announcement.  |
| Trend         | The trend indicator includes visually hidden text (`↑ Trending up` / `↓ Trending down`) so screen readers convey direction. |
| Screen reader | Value and label are read as a pair. Trend direction is announced after the value.                                           |
| Color         | Trend colors (`success` for up, `error` for down) are supplemented with directional icons — color is never the only signal. |
| WCAG          | Meets WCAG 2.1 AA. Trend direction is conveyed via both color and icon/text, meeting SC 1.4.1 (Use of Color).               |

## Drupal Integration

```twig
{# my-module/templates/stat-widget.html.twig #}
<hx-stat
  value="{{ value }}"
  label="{{ label }}"
  trend="{{ trend|default('neutral') }}"
  hx-size="{{ size|default('md') }}"
>
  {% if icon %}
    <hx-icon slot="icon" name="{{ icon }}"></hx-icon>
  {% endif %}
</hx-stat>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```
