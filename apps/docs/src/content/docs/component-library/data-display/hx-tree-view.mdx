## Overview

`hx-tree-view` renders a hierarchical tree of `hx-tree-item` elements with expand/collapse support and full keyboard navigation following the WAI-ARIA tree view pattern. It supports three selection modes: `none`, `single`, and `multiple`. The component uses a roving tabindex pattern so keyboard navigation feels native.

**Use `hx-tree-view` when:** you need to represent nested hierarchical data — organizational charts, ICD-10 code taxonomies, department navigation trees, file system explorers.

**Scale note:** All tree items are rendered simultaneously. For large datasets (500+ items), use the `expanded` property on `hx-tree-item` to lazy-load child branches.

## Installation

## Basic Usage

```html
<hx-tree-view label="Navigation tree" selection="single">
  <hx-tree-item>
    Section One
    <hx-tree-item slot="children">Child A</hx-tree-item>
    <hx-tree-item slot="children">Child B</hx-tree-item>
  </hx-tree-item>
  <hx-tree-item>Section Two</hx-tree-item>
</hx-tree-view>
```

## Properties

| Property    | Attribute   | Type                               | Default  | Description                                                                                                                              |
| ----------- | ----------- | ---------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `label`     | `label`     | `string`                           | `''`     | **Required for accessibility.** Applied as `aria-label` on the `role="tree"` container (WCAG 4.1.2). Emits a console warning if not set. |
| `selection` | `selection` | `'none' \| 'single' \| 'multiple'` | `'none'` | Selection mode. `single` deselects previous item on new selection. `multiple` allows concurrent selections. `none` disables selection.   |

## Events

| Event       | Detail                                       | Description                                                                                                 |
| ----------- | -------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `hx-select` | `{ item: HelixTreeItem, selected: boolean }` | Dispatched when a tree item is selected or deselected. `selected` is `true` on select, `false` on deselect. |

## CSS Custom Properties

| Property                | Default                      | Description       |
| ----------------------- | ---------------------------- | ----------------- |
| `--hx-tree-font-family` | `var(--hx-font-family-sans)` | Tree font family. |

## CSS Parts

| Part   | Description                                    |
| ------ | ---------------------------------------------- |
| `tree` | The tree container element with `role="tree"`. |

## Slots

| Slot        | Description                        |
| ----------- | ---------------------------------- |
| _(default)_ | Top-level `hx-tree-item` elements. |

## Accessibility

| Topic           | Details                                                                                                                                                                                                                                                                                                                              |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `role="tree"`   | The container uses `role="tree"` with `aria-label` from the `label` property. **Always provide a descriptive label** — its absence is a WCAG 4.1.2 violation.                                                                                                                                                                        |
| Tree items      | Each `hx-tree-item` uses `role="treeitem"` with `aria-expanded`, `aria-selected` (when selection is enabled), `aria-level`, `aria-posinset`, and `aria-setsize`.                                                                                                                                                                     |
| Keyboard        | `Arrow Down` / `Arrow Up`: move focus between visible items. `Arrow Right`: expand collapsed item, or move to first child if expanded. `Arrow Left`: collapse expanded item, or move to parent item. `Home` / `End`: jump to first / last visible item. `Enter` / `Space`: select the focused item (when `selection` is not `none`). |
| Roving tabindex | Only one tree item has `tabindex="0"` at a time (the active item). All others have `tabindex="-1"`. Tab enters the tree at the last active item and exits cleanly.                                                                                                                                                                   |
| Multi-select    | When `selection="multiple"`, `aria-multiselectable="true"` is set on the tree container so screen readers know multiple selections are possible.                                                                                                                                                                                     |

## Drupal Integration

```twig
{# my-module/templates/nav-tree.html.twig #}
<hx-tree-view
  label="{{ label }}"
  {% if selection %}selection="{{ selection }}"{% endif %}
>
  {% for item in items %}
    <hx-tree-item{% if item.value %} value="{{ item.value }}"{% endif %}>
      {{ item.label }}
      {% if item.children %}
        {% for child in item.children %}
          <hx-tree-item slot="children">{{ child.label }}</hx-tree-item>
        {% endfor %}
      {% endif %}
    </hx-tree-item>
  {% endfor %}
</hx-tree-view>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```

## Standalone HTML Example

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>hx-tree-view example</title>
    <!-- @helixui/library is a private package — install via npm workspace, not CDN -->
    <!-- In your project: import '@helixui/library'; in your bundler entry point -->
  </head>
  <body style="font-family: sans-serif; padding: 2rem; max-width: 400px;">
    <h2>Diagnosis Code Browser</h2>
    <hx-tree-view label="ICD-10 diagnosis code browser" selection="single" id="code-tree">
      <hx-tree-item>
        E — Endocrine, Nutritional, Metabolic
        <hx-tree-item slot="children" value="E11">
          E11 — Type 2 Diabetes Mellitus
          <hx-tree-item slot="children" value="E11.0">E11.0 — With hyperosmolarity</hx-tree-item>
          <hx-tree-item slot="children" value="E11.9">E11.9 — Without complications</hx-tree-item>
        </hx-tree-item>
        <hx-tree-item slot="children" value="E78"
          >E78 — Disorders of lipoprotein metabolism</hx-tree-item
        >
      </hx-tree-item>
      <hx-tree-item>
        I — Circulatory System
        <hx-tree-item slot="children" value="I10">I10 — Essential Hypertension</hx-tree-item>
        <hx-tree-item slot="children" value="I48">I48 — Atrial Fibrillation</hx-tree-item>
      </hx-tree-item>
    </hx-tree-view>

    <p id="selected-code" style="margin-top: 1rem; font-weight: bold; color: #1d4ed8;"></p>

    <script>
      document.getElementById('code-tree').addEventListener('hx-select', (e) => {
        const label = document.getElementById('selected-code');
        if (e.detail.selected) {
          label.textContent = 'Selected: ' + e.detail.item.textContent.trim();
        } else {
          label.textContent = '';
        }
      });
    </script>
  </body>
</html>
```
