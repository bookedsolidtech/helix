## Overview

`hx-code-snippet` renders a styled dark-theme code block with optional copy-to-clipboard, line numbers, and expand/collapse for long code. It supports both block (`<pre><code>`) and inline (`<code>`) rendering modes. No syntax highlighting is built in — a `language` attribute hint is applied as a `language-*` class on the `<code>` element so consumers can target it with an external highlighter (e.g., Prism, highlight.js).

**Use `hx-code-snippet` when:** you need to display code samples, command-line instructions, configuration files, or any pre-formatted text in healthcare documentation or admin UIs.

## Installation

```bash
# Full library
npm install @helixui/library

# Or import only this component (tree-shaking friendly)
import '@helixui/library/components/hx-code-snippet';
```

## Basic Usage

```html
<!-- Block mode (default) -->
<hx-code-snippet language="bash" copyable> npm install @helixui/library </hx-code-snippet>

<!-- Inline mode -->
<p>Use the <hx-code-snippet inline>hx-button</hx-code-snippet> component.</p>
```

## Properties

| Property        | Attribute         | Type      | Default       | Description                                                                                                 |
| --------------- | ----------------- | --------- | ------------- | ----------------------------------------------------------------------------------------------------------- |
| `language`      | `language`        | `string`  | `''`          | Language hint applied as a `language-*` class on `<code>`. Used by external syntax highlighters.            |
| `inline`        | `inline`          | `boolean` | `false`       | When true, renders as an inline `<code>` element instead of a `<pre><code>` block.                          |
| `wrap`          | `wrap`            | `boolean` | `false`       | When true, enables word-wrap in block mode.                                                                 |
| `copyable`      | `copyable`        | `boolean` | `false`       | When true, shows a copy-to-clipboard button in the header.                                                  |
| `maxLines`      | `max-lines`       | `number`  | `0`           | Maximum lines to show before a "Show more" button appears. Set to `0` to disable truncation.                |
| `lineNumbers`   | `line-numbers`    | `boolean` | `false`       | When true, prepends line numbers in block mode. Line numbers are `aria-hidden` so screen readers skip them. |
| `labelCopy`     | `label-copy`      | `string`  | `'Copy code'` | Accessible label and visible text for the copy button in idle state. Override for i18n.                     |
| `labelCopied`   | `label-copied`    | `string`  | `'Copied!'`   | Label shown on the copy button after a successful copy. Override for i18n.                                  |
| `labelShowMore` | `label-show-more` | `string`  | `'Show more'` | Label for the expand button when content is collapsed. Override for i18n.                                   |
| `labelShowLess` | `label-show-less` | `string`  | `'Show less'` | Label for the expand button when content is expanded. Override for i18n.                                    |

## Events

| Event     | Detail             | Description                                                                          |
| --------- | ------------------ | ------------------------------------------------------------------------------------ |
| `hx-copy` | `{ text: string }` | Dispatched when the copy button is clicked. `text` contains the copied code content. |

## CSS Parts

| Part            | Description                                                  |
| --------------- | ------------------------------------------------------------ |
| `base`          | The outermost container (`<div>` or `<code>`).               |
| `header`        | The header bar containing the copy button (block mode only). |
| `code`          | The `<code>` element containing the content.                 |
| `copy-button`   | The copy-to-clipboard button.                                |
| `expand-button` | The "Show more / Show less" expand button.                   |

## Slots

| Slot        | Description                                                                                                              |
| ----------- | ------------------------------------------------------------------------------------------------------------------------ |
| _(default)_ | Code content as plain text. HTML markup in slot content will be stripped — only text content is extracted and displayed. |

## Accessibility

| Topic           | Details                                                                                                                                              |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `role="region"` | The `<pre>` element uses `role="region"` with `aria-label` (e.g., "Code snippet: javascript") so screen readers can identify the code block.         |
| Copy feedback   | A visually-hidden `aria-live="polite"` region announces the `labelCopied` text after a successful copy, informing screen reader users of the action. |
| Line numbers    | Line number `<span>` elements are `aria-hidden="true"` so they are skipped by screen readers and do not pollute the read-aloud content.              |
| Expand button   | The expand button carries `aria-expanded` (`"true"` / `"false"`) to convey collapsed/expanded state to assistive technology.                         |

## Drupal Integration

```twig
{# my-module/templates/code-example.html.twig #}
<hx-code-snippet
  language="{{ language|default('') }}"
  {% if copyable %}copyable{% endif %}
  {% if line_numbers %}line-numbers{% endif %}
  {% if max_lines %}max-lines="{{ max_lines }}"{% endif %}
>{{ code }}</hx-code-snippet>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```

## Standalone HTML Example

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>hx-code-snippet example</title>
    <!-- @helixui/library is a private package — install via npm workspace, not CDN -->
    <!-- In your project: import '@helixui/library'; in your bundler entry point -->
  </head>
  <body style="font-family: sans-serif; padding: 2rem; max-width: 700px; margin: 0 auto;">
    <h2>Installation</h2>
    <hx-code-snippet language="bash" copyable>npm install @helixui/library</hx-code-snippet>

    <h2>Component Usage</h2>
    <hx-code-snippet language="html" copyable line-numbers>
      &lt;hx-button variant="primary"&gt;Save Patient&lt;/hx-button&gt; &lt;hx-button
      variant="secondary"&gt;Cancel&lt;/hx-button&gt;
    </hx-code-snippet>

    <h2>Configuration (truncated)</h2>
    <hx-code-snippet language="json" max-lines="4" copyable>
      { "organization": "General Hospital", "theme": "healthcare-default", "locale": "en-US",
      "timezone": "America/New_York", "features": ["appointments", "lab-results", "messaging"] }
    </hx-code-snippet>

    <script>
      document.querySelectorAll('hx-code-snippet').forEach((el) => {
        el.addEventListener('hx-copy', (e) => {
          console.log('Copied:', e.detail.text.substring(0, 40) + '...');
        });
      });
    </script>
  </body>
</html>
```
