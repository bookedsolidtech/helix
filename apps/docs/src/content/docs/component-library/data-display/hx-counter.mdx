## Overview

`hx-counter` renders a single numeric metric that animates from zero to a target `value` when the component mounts. It supports prefix/suffix text (e.g., `$` or `%`), two number formats (integer and decimal), three size variants, and four easing functions.

**Use `hx-counter` when:** you want a visually impactful, animated number display — patient counts, revenue figures, appointment totals.

**Use `hx-stat` instead when:** you need a labeled metric with a trend indicator and contextual label below the value.

## Properties

| Property   | Attribute  | Type                                                   | Default      | Description                                                                                      |
| ---------- | ---------- | ------------------------------------------------------ | ------------ | ------------------------------------------------------------------------------------------------ |
| `value`    | `value`    | `number`                                               | `0`          | The target numeric value to count to.                                                            |
| `duration` | `duration` | `number`                                               | `1000`       | Animation duration in milliseconds.                                                              |
| `easing`   | `easing`   | `'linear' \| 'ease-in' \| 'ease-out' \| 'ease-in-out'` | `'ease-out'` | Easing function applied to the animation progress.                                               |
| `format`   | `format`   | `'integer' \| 'decimal'`                               | `'integer'`  | Number format. `integer` rounds to the nearest whole number; `decimal` shows two decimal places. |
| `prefix`   | `prefix`   | `string`                                               | `''`         | String prepended to the formatted value (e.g., `$`).                                             |
| `suffix`   | `suffix`   | `string`                                               | `''`         | String appended to the formatted value (e.g., `%`).                                              |
| `size`     | `hx-size`  | `'sm' \| 'md' \| 'lg'`                                 | `'md'`       | Size variant controlling font size.                                                              |

## Events

## Accessibility

| Topic          | Details                                                                                                                                   |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| ARIA role      | `role="timer"` applied to the counter element to convey animated numeric content to assistive technologies.                               |
| `aria-live`    | The counter element uses `aria-live="polite"` so screen readers announce the final value after the animation completes.                   |
| Screen reader  | The final formatted value (including prefix/suffix) is announced when the animation ends.                                                 |
| Reduced motion | When `prefers-reduced-motion: reduce` is active, the counter skips animation and renders the final value immediately, meeting WCAG 2.3.3. |

## Drupal Integration

```twig
{# my-module/templates/stats-block.html.twig #}
<hx-counter
  value="{{ count }}"
  prefix="{{ prefix|default('') }}"
  suffix="{{ suffix|default('') }}"
  hx-size="{{ size|default('md') }}"
  format="{{ format|default('integer') }}"
></hx-counter>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```
