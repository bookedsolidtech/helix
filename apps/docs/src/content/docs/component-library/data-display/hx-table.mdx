## Overview

`hx-table` wraps a semantic `<table>` element with variant-based styling, an optional sticky header, and responsive horizontal scrolling. It accepts `hx-thead`, `hx-tbody`, and `hx-tfoot` sub-components as slotted children and requires a `label` property for accessibility.

**Use `hx-table` when:** you need to present tabular data — patient records, lab results, appointment lists — in a semantically correct, accessible table structure.

**Use `hx-data-table` instead when:** you need built-in sorting, filtering, pagination, and row selection behavior on top of the table structure.

## Properties

| Property       | Attribute       | Type                                             | Default     | Description                                                                                     |
| -------------- | --------------- | ------------------------------------------------ | ----------- | ----------------------------------------------------------------------------------------------- |
| `label`        | `label`         | `string`                                         | `''`        | **Required for accessibility.** Exposed as `aria-label` on the `<table>` element (WCAG 4.1.2).  |
| `caption`      | `caption`       | `string`                                         | `''`        | Visible caption text. Renders a `<caption>` element. Use the `caption` slot for richer content. |
| `variant`      | `variant`       | `'default' \| 'striped' \| 'hover' \| 'compact'` | `'default'` | Visual variant controlling row styling.                                                         |
| `stickyHeader` | `sticky-header` | `boolean`                                        | `false`     | When true, the header row stays fixed while the table body scrolls.                             |
| `fullWidth`    | `full-width`    | `boolean`                                        | `true`      | When true, the table expands to fill 100% of its container width.                               |

## Events

`hx-table` does not dispatch any custom events.

| Part      | Description              |
| --------- | ------------------------ |
| `table`   | The `<table>` element.   |
| `caption` | The `<caption>` element. |

## Slots

| Slot        | Description                                                                                         |
| ----------- | --------------------------------------------------------------------------------------------------- |
| _(default)_ | Accepts `<thead>`, `<tbody>`, and `<tfoot>` (or `hx-thead`, `hx-tbody`, `hx-tfoot`) sub-components. |
| `caption`   | Custom caption content rendered inside the `<caption>` element.                                     |

## Accessibility

| Topic         | Details                                                                                                                                        |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `aria-label`  | Applied to the `<table>` element from the `label` property. **Always provide a descriptive label** (e.g., `"Patient appointments for March"`). |
| Caption       | Use the `caption` property or slot for a visible table title. This supplements `aria-label` for users who browse by table.                     |
| Header cells  | Use `<th scope="col">` for column headers and `<th scope="row">` for row headers inside the slotted content.                                   |
| Keyboard      | Standard table keyboard navigation: `Tab` moves through interactive cells; arrow keys are not intercepted by the component.                    |
| Screen reader | Table structure (rows, columns, headers) is announced natively by the browser. The `label` provides context for the table as a whole.          |
| Responsive    | The table wrapper scrolls horizontally when content overflows, preserving table structure rather than collapsing rows.                         |
| WCAG          | Meets WCAG 2.1 AA when `label` is provided and `<th>` elements include `scope` attributes on all header cells.                                 |

## Drupal Integration

```twig
{# my-module/templates/data-table.html.twig #}
<hx-table
  label="{{ table_label }}"
  variant="{{ variant|default('default') }}"
  {% if sticky_header %}sticky-header{% endif %}
>
  <table>
    <thead>
      <tr>
        {% for header in headers %}
          <th scope="col">{{ header }}</th>
        {% endfor %}
      </tr>
    </thead>
    <tbody>
      {% for row in rows %}
        <tr>
          {% for cell in row %}
            <td>{{ cell }}</td>
          {% endfor %}
        </tr>
      {% endfor %}
    </tbody>
  </table>
</hx-table>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```
