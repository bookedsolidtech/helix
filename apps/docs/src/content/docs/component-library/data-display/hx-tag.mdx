## Overview

`hx-tag` is a compact inline label used for categorization, filtering, and status indication. It supports five semantic color variants, three sizes, pill (fully rounded) styling, prefix/suffix slots for icons or avatars, and an optional dismiss/remove button.

**Use `hx-tag` when:** you need to label records, display active filters, show status badges, or allow users to dismiss applied criteria — patient diagnoses, allergy categories, applied search filters.

## Basic Usage

```html
<!-- Status label -->
<hx-tag variant="success">Active</hx-tag>

<!-- Removable filter tag -->
<hx-tag variant="primary" removable>Cardiology</hx-tag>

<!-- Pill style with icon prefix -->
<hx-tag variant="danger" pill removable>
  <hx-icon slot="prefix" name="warning"></hx-icon>
  Critical
</hx-tag>
```

## Properties

| Property    | Attribute   | Type                                                           | Default     | Description                                                                                            |
| ----------- | ----------- | -------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------ |
| `variant`   | `variant`   | `'default' \| 'primary' \| 'success' \| 'warning' \| 'danger'` | `'default'` | Visual style variant. `success`, `warning`, and `danger` also render a visually-hidden semantic label. |
| `size`      | `hx-size`   | `'sm' \| 'md' \| 'lg'`                                         | `'md'`      | Size variant. Use `hx-size` attribute in HTML/Twig; the `size` property in JavaScript.                 |
| `pill`      | `pill`      | `boolean`                                                      | `false`     | When true, applies fully rounded pill styling.                                                         |
| `removable` | `removable` | `boolean`                                                      | `false`     | When true, renders a dismiss/remove button.                                                            |
| `disabled`  | `disabled`  | `boolean`                                                      | `false`     | When true, disables all interactions including the remove button.                                      |

## Events

| Event       | Detail | Description                                        |
| ----------- | ------ | -------------------------------------------------- |
| `hx-remove` | `void` | Dispatched when the user clicks the remove button. |

## CSS Parts

| Part            | Description                            |
| --------------- | -------------------------------------- |
| `base`          | The root `<span>` element.             |
| `prefix`        | The prefix slot wrapper.               |
| `label`         | The label slot wrapper.                |
| `suffix`        | The suffix slot wrapper.               |
| `remove-button` | The remove/dismiss `<button>` element. |

## Slots

| Slot        | Description                                       |
| ----------- | ------------------------------------------------- |
| _(default)_ | Tag label text.                                   |
| `prefix`    | Icon or avatar rendered before the label.         |
| `suffix`    | Content rendered after the label (before remove). |

## Accessibility

| Topic           | Details                                                                                                                                                                                                                                                         |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Semantic labels | `success`, `warning`, and `danger` variants render a visually hidden text prefix ("Success: ", "Warning: ", "Danger: ") so screen reader users receive the semantic context even when color cannot be perceived (WCAG 1.4.1).                                   |
| Remove button   | The remove button's `aria-label` is automatically set to "Remove [label text]" using the text content of the default slot (e.g., "Remove Penicillin"). This provides a meaningful label without exposing prefix/suffix icon text.                               |
| Disabled        | When `disabled`, the remove button receives the native `disabled` attribute, preventing focus and click events.                                                                                                                                                 |
| Live regions    | When tags are programmatically removed from the DOM, the consuming application is responsible for announcing the change via its own `aria-live` region. This is a deliberate design decision — clinical filter changes need application-specific announcements. |

## Drupal Integration

```twig
{# my-module/templates/patient-tag.html.twig #}
<hx-tag
  variant="{{ variant|default('default') }}"
  hx-size="{{ size|default('md') }}"
  {% if pill %}pill{% endif %}
  {% if removable %}removable{% endif %}
  {% if disabled %}disabled{% endif %}
>{{ label }}</hx-tag>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```

## Standalone HTML Example

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>hx-tag example</title>
    <!-- @helixui/library is a private package — install via npm workspace, not CDN -->
    <!-- In your project: import '@helixui/library'; in your bundler entry point -->
  </head>
  <body style="font-family: sans-serif; padding: 2rem;">
    <h2>Active Filters</h2>
    <div id="filter-tags" style="display: flex; gap: 0.5rem; flex-wrap: wrap;" aria-live="polite">
      <hx-tag variant="primary" removable>Cardiology</hx-tag>
      <hx-tag variant="primary" removable>Admitted Today</hx-tag>
      <hx-tag variant="warning" removable>Awaiting Labs</hx-tag>
    </div>

    <h2>Allergy Labels</h2>
    <div style="display: flex; gap: 0.5rem; flex-wrap: wrap;">
      <hx-tag variant="danger" pill>Penicillin</hx-tag>
      <hx-tag variant="warning" pill>Sulfa</hx-tag>
      <hx-tag variant="danger" pill>Latex</hx-tag>
    </div>

    <script>
      document.querySelectorAll('hx-tag[removable]').forEach((tag) => {
        tag.addEventListener('hx-remove', () => {
          tag.remove();
        });
      });
    </script>
  </body>
</html>
```
