## Overview

`hx-phi-field` renders Protected Health Information (PHI) in a masked state by default. Users must explicitly reveal the value via a toggle button. Every reveal, hide, and clipboard clear action dispatches an `hx-phi-access` audit event that applications can capture for HIPAA compliance logging.

**Key HIPAA protections:**

- PHI is set via JavaScript property only (`element.data = "..."`) — never as an HTML attribute
- If a `data` attribute is detected (e.g., from SSR), the component rescues the value into the JS property and strips the attribute from the DOM
- Clipboard is automatically cleared after a configurable timeout (default: 30 seconds)
- Clipboard is immediately cleared when the browser tab loses visibility
- Masking patterns are field-type-aware (SSN shows last 4 digits, DOB fully masked, etc.)

**Use `hx-phi-field` when:** displaying Social Security Numbers, Medical Record Numbers, dates of birth, insurance IDs, or any protected health information in a clinical interface.

## Basic Usage

```html
<hx-phi-field field-type="ssn" field-id="patient-ssn" label="Social Security Number"></hx-phi-field>

<script>
  // PHI MUST be set via JavaScript property — never as an HTML attribute
  const field = document.querySelector('hx-phi-field');
  field.data = '123-45-6789';
</script>
```

## Properties

| Property           | Attribute           | Type                                     | Default | Description                                                     |
| ------------------ | ------------------- | ---------------------------------------- | ------- | --------------------------------------------------------------- |
| `data`             | _(none — JS only)_  | `string`                                 | `''`    | The PHI value. Must be set via JS property, not HTML attribute. |
| `fieldType`        | `field-type`        | `'ssn' \| 'mrn' \| 'dob' \| 'insurance'` | `'ssn'` | Controls the masking pattern applied.                           |
| `fieldId`          | `field-id`          | `string`                                 | `''`    | Identifier used in audit events. Falls back to `id` attribute.  |
| `clipboardTimeout` | `clipboard-timeout` | `number`                                 | `30000` | Milliseconds before clipboard auto-clear.                       |
| `label`            | `label`             | `string`                                 | `''`    | Accessible label prefix for screen reader announcements.        |
| `disabled`         | `disabled`          | `boolean`                                | `false` | Disables all interaction and prevents reveal.                   |

## Events

| Event           | Detail Type            | Description                                                                               |
| --------------- | ---------------------- | ----------------------------------------------------------------------------------------- |
| `hx-phi-access` | `PhiAccessEventDetail` | Fired on reveal, hide, and clipboard-clear. Contains audit metadata only — never raw PHI. |

### PhiAccessEventDetail

```ts
interface PhiAccessEventDetail {
  fieldId: string; // Developer-assigned identifier (NOT PHI)
  action: 'reveal' | 'hide' | 'clipboard-clear';
  timestamp: string; // ISO 8601
  fieldType: 'ssn' | 'mrn' | 'dob' | 'insurance';
}
```

## Security Model

The `hx-phi-access` event is dispatched with `composed: true` to cross shadow DOM boundaries for application-level audit listeners. **Raw PHI is never included in event details.**

In multi-tenant micro-frontend architectures, scope `hx-phi-access` listeners to the appropriate DOM subtree to prevent cross-patient event leakage.

See the [CSP guide](/guides/csp/) for Content Security Policy configuration.

## Accessibility

| Topic         | Details                                                    |
| ------------- | ---------------------------------------------------------- |
| ARIA role     | `role="status"` on mask state announcements (polite)       |
| Keyboard      | Toggle button is Tab-focusable; Enter/Space toggles reveal |
| Screen reader | Announces "is masked" / "is revealed" via live region      |
| Focus         | Focus remains on toggle button after interaction           |
