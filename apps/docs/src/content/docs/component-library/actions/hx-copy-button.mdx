## Overview

`hx-copy-button` writes a given value to the system clipboard on click. It provides idle and success states with a configurable feedback duration, slot-based icon overrides, and an accessible live region that announces copy completion to screen reader users.

The `aria-label` reflects the current copy state: idle shows `label`; after copy it appends `" — Copied"` so screen reader users who re-focus the button receive an accurate accessible name.

**Note:** `aria-pressed` is intentionally not used. The copied state is transient feedback, not a persistent on/off toggle.

## Installation

```bash

import '@helixui/library/components/hx-copy-button';
```

## Basic Usage

```html
<hx-copy-button value="Text to copy"></hx-copy-button>
```

## Custom Icons

Override the default icons using named slots:

```html
<hx-copy-button value="Custom icons">
  <hx-icon slot="copy-icon" name="clipboard"></hx-icon>
  <hx-icon slot="success-icon" name="check"></hx-icon>
</hx-copy-button>
```

## Properties

| Property           | Attribute           | Type                   | Default               | Description                                                                                                                       |
| ------------------ | ------------------- | ---------------------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `value`            | `value`             | `string`               | `''`                  | The text value to write to the clipboard on click.                                                                                |
| `label`            | `label`             | `string`               | `'Copy to clipboard'` | Accessible label applied as `aria-label` and `title` on the button.                                                               |
| `feedbackDuration` | `feedback-duration` | `number`               | `2000`                | Duration in milliseconds to display the success state before reverting. Values below 300 ms are clamped to 300 ms.                |
| `size`             | `hx-size`           | `'sm' \| 'md' \| 'lg'` | `'md'`                | Visual size of the button. Invalid values are silently coerced to `'md'`.                                                         |
| `disabled`         | `disabled`          | `boolean`              | `false`               | Whether the button is disabled. Click events and clipboard writes are suppressed.                                                 |
| `labelCopied`      | `label-copied`      | `string`               | `'Copied'`            | Text announced to screen readers and appended to `aria-label` after a successful copy. Also used in the `aria-live` announcement. |
| `labelError`       | `label-error`       | `string`               | `'Copy failed'`       | Accessible label announced when copy fails. Override for i18n.                                                                    |

## Events

| Event           | Detail Type                       | Description                                                                              |
| --------------- | --------------------------------- | ---------------------------------------------------------------------------------------- |
| `hx-copy`       | `{ value: string }`               | Dispatched after the value has been successfully written to the clipboard.               |
| `hx-copy-error` | `{ value: string; error: Error }` | Dispatched when the clipboard write fails (permission denied, iframe restriction, etc.). |

## CSS Parts

| Part     | Description                                                |
| -------- | ---------------------------------------------------------- |
| `button` | The native `<button>` element.                             |
| `icon`   | The icon container `<span>` wrapping the active icon slot. |

## Slots

| Slot           | Description                                                        |
| -------------- | ------------------------------------------------------------------ |
| _(default)_    | Optional label text rendered inside the button alongside the icon. |
| `copy-icon`    | Icon shown in the idle (pre-copy) state.                           |
| `success-icon` | Icon shown after a successful clipboard write.                     |

## Accessibility

| Topic        | Details                                                                                                                            |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| ARIA role    | Inherits native `button` role.                                                                                                     |
| `aria-label` | Set from `label` in idle state; appends `" — {labelCopied}"` during the copied feedback window (WCAG 1.3.1).                       |
| `title`      | Always set from `label` for a persistent tooltip.                                                                                  |
| Live region  | An `aria-live="polite"` region announces the copied or error state to screen readers on copy action.                               |
| Keyboard     | `Tab` to focus; `Enter` / `Space` to activate.                                                                                     |
| WCAG 2.5.8   | The `sm` size uses `--hx-size-8` for minimum target size. Prefer `md` or `lg` for touch-primary interfaces (44×44 px recommended). |

## Drupal Integration

```twig
{# my-module/templates/copy-button.html.twig #}
<hx-copy-button
  value="{{ value }}"
  label="{{ label|default('Copy to clipboard') }}"
  hx-size="{{ size|default('md') }}"
  {% if disabled %}disabled{% endif %}
></hx-copy-button>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```

Listen for events in Drupal behaviors:

```javascript
Drupal.behaviors.helixCopyButton = {
  attach(context) {
    once('helixCopyButton', 'hx-copy-button', context).forEach((el) => {
      el.addEventListener('hx-copy', (e) => {
        console.log('Copied:', e.detail.value);
      });
      el.addEventListener('hx-copy-error', (e) => {
        console.error('Copy failed:', e.detail.error);
      });
    });
  },
};
```
