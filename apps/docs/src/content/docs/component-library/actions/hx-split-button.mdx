## Overview

`hx-split-button` combines a primary action button with an attached dropdown menu for secondary actions. It implements the ARIA menu button pattern for full keyboard and screen reader support.

The component consists of two buttons: the **primary button** (triggers `hx-click`) and the **dropdown trigger button** (opens the menu). Menu items are `hx-menu-item` elements placed in the `menu` slot.

**Use `hx-split-button` when:** there is one clear primary action plus a set of related secondary actions that don't need to be visible at all times.

## Properties

| Property       | Attribute       | Type                                                                         | Default               | Description                                                                   |
| -------------- | --------------- | ---------------------------------------------------------------------------- | --------------------- | ----------------------------------------------------------------------------- |
| `variant`      | `variant`       | `'primary' \| 'secondary' \| 'tertiary' \| 'danger' \| 'ghost' \| 'outline'` | `'primary'`           | Visual style variant of the split button.                                     |
| `size`         | `hx-size`       | `'sm' \| 'md' \| 'lg'`                                                       | `'md'`                | Size of the split button.                                                     |
| `disabled`     | `disabled`      | `boolean`                                                                    | `false`               | Disables both the primary button and the dropdown trigger.                    |
| `label`        | `label`         | `string \| undefined`                                                        | `undefined`           | Primary button label text. When set, overrides the default slot content.      |
| `ariaLabel`    | `aria-label`    | `string`                                                                     | `''`                  | Accessible label for the primary action button. Required for icon-only usage. |
| `labelTrigger` | `label-trigger` | `string`                                                                     | `'More actions'`      | Accessible label for the dropdown trigger button. Override for localization.  |
| `labelMenu`    | `label-menu`    | `string`                                                                     | `'Secondary actions'` | Accessible label for the dropdown menu panel. Override for localization.      |

## Events

| Event       | Detail Type                        | Description                                                        |
| ----------- | ---------------------------------- | ------------------------------------------------------------------ |
| `hx-click`  | `{ originalEvent: MouseEvent }`    | Dispatched when the primary button is clicked and is not disabled. |
| `hx-select` | `{ value: string; label: string }` | Dispatched when a menu item is selected from the dropdown.         |

## CSS Parts

| Part      | Description                          |
| --------- | ------------------------------------ |
| `button`  | The primary action button element.   |
| `trigger` | The dropdown trigger button element. |
| `menu`    | The dropdown menu panel element.     |

## Slots

| Slot        | Description                                             |
| ----------- | ------------------------------------------------------- |
| _(default)_ | Primary button label text.                              |
| `menu`      | `hx-menu-item` children rendered in the dropdown panel. |

## Keyboard Interaction

| Key         | Behavior                                                         |
| ----------- | ---------------------------------------------------------------- |
| `Tab`       | Moves focus between the primary button and the trigger button.   |
| `ArrowDown` | Opens the dropdown menu and focuses the first enabled menu item. |
| `ArrowUp`   | Moves focus to the previous menu item; wraps to last from first. |
| `ArrowDown` | Moves focus to the next menu item; wraps to first from last.     |
| `Home`      | Moves focus to the first menu item.                              |
| `End`       | Moves focus to the last menu item.                               |
| `Escape`    | Closes the menu and returns focus to the trigger button.         |
| `Tab`       | Closes the menu (focus moves to next focusable element in page). |

## Accessibility

| Topic           | Details                                                                      |
| --------------- | ---------------------------------------------------------------------------- |
| ARIA role       | Primary button: native `button`. Trigger button: `aria-haspopup="menu"`.     |
| `aria-expanded` | Set on the trigger button; reflects whether the dropdown is open.            |
| `aria-controls` | Trigger button is wired to the menu panel via a stable unique ID.            |
| Menu panel      | Has `role="menu"` and `aria-label` from `labelMenu`.                         |
| Outside click   | Clicking outside the component closes the menu.                              |
| WCAG            | Implements the ARIA Menu Button pattern (WAI-ARIA Authoring Practices 3.15). |

## Drupal Integration

```twig
{# my-module/templates/split-button.html.twig #}
<hx-split-button
  label="{{ primary_label }}"
  variant="{{ variant|default('primary') }}"
  hx-size="{{ size|default('md') }}"
  {% if disabled %}disabled{% endif %}
>
  {% for item in menu_items %}
    <hx-menu-item slot="menu" value="{{ item.value }}">{{ item.label }}</hx-menu-item>
  {% endfor %}
</hx-split-button>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```

Listen for events in Drupal behaviors:

```javascript
Drupal.behaviors.helixSplitButton = {
  attach(context) {
    once('helixSplitButton', 'hx-split-button', context).forEach((el) => {
      el.addEventListener('hx-click', (e) => {
        console.log('Primary action clicked:', e.detail.originalEvent);
      });
      el.addEventListener('hx-select', (e) => {
        console.log('Menu item selected:', e.detail.value, e.detail.label);
      });
    });
  },
};
```
