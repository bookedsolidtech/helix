## Overview

`hx-button-group` is a container component that groups related `hx-button` elements into a cohesive horizontal or vertical action set. It eliminates double borders between adjacent buttons and squares off inner border-radius for a unified visual appearance.

**Always provide an accessible label** via `aria-label` or `aria-labelledby` so screen readers can announce the group purpose.

**Use `hx-button-group` when:** you have two or more closely related actions that form a logical unit (e.g., Bold / Italic / Underline, or Align Left / Center / Right).

## Basic Usage

```html
<hx-button-group label="Text formatting">
  <hx-button variant="secondary">Bold</hx-button>
  <hx-button variant="secondary">Italic</hx-button>
  <hx-button variant="secondary">Underline</hx-button>
</hx-button-group>
```

## Properties

| Property      | Attribute     | Type                         | Default        | Description                                                                                                                       |
| ------------- | ------------- | ---------------------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `orientation` | `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Layout orientation of the button group. Invalid values are coerced to `'horizontal'` with a console warning.                      |
| `size`        | `hx-size`     | `'sm' \| 'md' \| 'lg'`       | `'md'`         | Size applied to the button group and cascaded to child buttons via `--hx-button-group-size`.                                      |
| `label`       | `label`       | `string`                     | `''`           | Accessible label for the button group. Sets `aria-label` via `ElementInternals`. Strongly recommended for WCAG 2.1 AA compliance. |

## CSS Custom Properties

| Property                 | Default | Description                                                               |
| ------------------------ | ------- | ------------------------------------------------------------------------- |
| `--hx-button-group-size` | `md`    | Size token forwarded to child buttons. Accepts `'sm'`, `'md'`, or `'lg'`. |

## CSS Parts

| Part    | Description                                                 |
| ------- | ----------------------------------------------------------- |
| `group` | The container `<div>` element wrapping all slotted buttons. |

## Slots

| Slot        | Description                             |
| ----------- | --------------------------------------- |
| _(default)_ | `hx-button` children to group together. |

## Accessibility

| Topic        | Details                                                                                                                      |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| ARIA role    | `group` — set via `ElementInternals.role` in the constructor.                                                                |
| `aria-label` | Set from the `label` property via `ElementInternals.ariaLabel`. Without a label, screen readers announce an unnamed "group". |
| Keyboard     | Each child button is individually focusable with `Tab`. No roving tabindex — standard group navigation.                      |
| WCAG         | Meets WCAG 2.1 AA (WCAG 4.1.2). A missing `label` emits a console warning during development.                                |

## Drupal Integration

```twig
{# my-module/templates/button-group.html.twig #}
<hx-button-group
  label="{{ group_label }}"
  orientation="{{ orientation|default('horizontal') }}"
  hx-size="{{ size|default('md') }}"
>
  {% for button in buttons %}
    <hx-button variant="{{ button.variant|default('secondary') }}">
      {{ button.label }}
    </hx-button>
  {% endfor %}
</hx-button-group>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```
