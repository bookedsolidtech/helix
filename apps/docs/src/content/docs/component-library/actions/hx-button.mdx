## Overview

`hx-button` is a production-grade button component supporting multiple visual variants, sizes, loading state, prefix/suffix icon slots, anchor rendering, and full ElementInternals form association.

**Use `hx-button` when:** a visible text label is needed for clarity, you need form submission behavior, or you need loading state feedback.

**Use `hx-icon-button` instead when:** the action is universally understood from an icon alone and space is at a premium.

## Installation

```bash

import '@helixui/library/components/hx-button';
```

## Basic Usage

```html
<hx-button variant="primary">Save Changes</hx-button>
```

## Properties

| Property   | Attribute  | Type                                                                         | Default     | Description                                                                                       |
| ---------- | ---------- | ---------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------- |
| `variant`  | `variant`  | `'primary' \| 'secondary' \| 'tertiary' \| 'danger' \| 'ghost' \| 'outline'` | `'primary'` | Visual style variant of the button.                                                               |
| `size`     | `hx-size`  | `'sm' \| 'md' \| 'lg'`                                                       | `'md'`      | Size of the button.                                                                               |
| `disabled` | `disabled` | `boolean`                                                                    | `false`     | Prevents all interaction and form actions.                                                        |
| `loading`  | `loading`  | `boolean`                                                                    | `false`     | Shows spinner, prevents interaction, and sets `aria-busy`. Does not set the `disabled` attribute. |
| `full`     | `full`     | `boolean`                                                                    | `false`     | When true, the button stretches to fill its container width.                                      |
| `inverted` | `inverted` | `boolean`                                                                    | `false`     | Flips button colors for placement on dark or gradient backgrounds.                                |
| `type`     | `type`     | `'button' \| 'submit' \| 'reset'`                                            | `'button'`  | The type attribute for the underlying button element. Ignored when `href` is set.                 |
| `href`     | `href`     | `string \| undefined`                                                        | `undefined` | When set, renders an `<a>` element instead of a `<button>`.                                       |
| `target`   | `target`   | `string \| undefined`                                                        | `undefined` | Anchor target attribute. Only used when `href` is set.                                            |
| `name`     | `name`     | `string \| undefined`                                                        | `undefined` | Form field name submitted via `ElementInternals.setFormValue` on submit.                          |
| `value`    | `value`    | `string \| undefined`                                                        | `undefined` | Form field value submitted via `ElementInternals.setFormValue` on submit.                         |

## Events

| Event      | Detail Type                     | Description                                                                |
| ---------- | ------------------------------- | -------------------------------------------------------------------------- |
| `hx-click` | `{ originalEvent: MouseEvent }` | Dispatched when the button is clicked and is neither disabled nor loading. |

## CSS Parts

| Part      | Description                             |
| --------- | --------------------------------------- |
| `button`  | The native `<button>` or `<a>` element. |
| `label`   | The label text wrapper `<span>`.        |
| `prefix`  | The prefix slot container `<span>`.     |
| `suffix`  | The suffix slot container `<span>`.     |
| `spinner` | The loading spinner `<svg>` element.    |

## Slots

| Slot        | Description                                |
| ----------- | ------------------------------------------ |
| _(default)_ | Button label text or content.              |
| `prefix`    | Icon or content rendered before the label. |
| `suffix`    | Icon or content rendered after the label.  |

## Accessibility

| Topic        | Details                                                                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| ARIA role    | Inherits native `button` role (or `link` when `href` is set).                                                                               |
| `aria-busy`  | Set to `"true"` during loading state.                                                                                                       |
| `aria-label` | Delegated from the `aria-label` attribute on the host via `mixinDelegatesAria`.                                                             |
| Keyboard     | `Tab` to focus; `Enter` / `Space` to activate.                                                                                              |
| Form         | Uses `ElementInternals` for form association. Setting `type="submit"` triggers `form.requestSubmit()`; `type="reset"` calls `form.reset()`. |
| WCAG         | Meets WCAG 2.1 AA. A missing label emits a console warning during development.                                                              |

## Drupal Integration

```twig
{# my-module/templates/button.html.twig #}
<hx-button
  variant="{{ variant|default('primary') }}"
  hx-size="{{ size|default('md') }}"
  {% if disabled %}disabled{% endif %}
  {% if loading %}loading{% endif %}
  {% if full %}full{% endif %}
>
  {{ label }}
</hx-button>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```

Listen for events in Drupal behaviors:

```javascript
Drupal.behaviors.helixButton = {
  attach(context) {
    once('helixButton', 'hx-button', context).forEach((el) => {
      el.addEventListener('hx-click', (e) => {
        console.log('Button clicked:', e.detail.originalEvent);
      });
    });
  },
};
```

```html
    <meta charset="UTF-8" />

    style="font-family: sans-serif; padding: 2rem; display: flex; gap: 1rem; flex-wrap: wrap; align-items: center;"
  >
    <hx-button variant="primary" id="save-btn">Save Changes</hx-button>
    <hx-button variant="secondary">Cancel</hx-button>
    <hx-button variant="danger">Delete</hx-button>
    <hx-button loading>Saving…</hx-button>
    <hx-button disabled>Disabled</hx-button>

    <!-- Anchor mode -->
    <hx-button href="/dashboard" variant="ghost">Go to Dashboard</hx-button>

    <script>
      document.getElementById('save-btn').addEventListener('hx-click', (e) => {
        console.log('Save clicked:', e.detail.originalEvent);
      });
    </script>
  </body>
</html>
```
