## Overview

`hx-toggle-button` is a two-state button that communicates pressed/unpressed status to assistive technology via `aria-pressed`. It supports multiple visual variants and sizes, prefix/suffix slots, full `ElementInternals` form association, and a distinct pressed visual state for every variant.

**Use `hx-toggle-button` when:** you need a binary on/off state, such as bold/italic formatting, mute/unmute, or favorite/unfavorite.

**Use `hx-button` instead when:** you need a one-time action without persistent state.

## Basic Usage

```html
<hx-toggle-button variant="secondary" id="bold-btn">Bold</hx-toggle-button>

<script>
  document.getElementById('bold-btn').addEventListener('hx-toggle', (e) => {
    console.log('Bold pressed:', e.detail.pressed);
  });
</script>
```

## Properties

| Property   | Attribute  | Type                                                             | Default       | Description                                                                                                |
| ---------- | ---------- | ---------------------------------------------------------------- | ------------- | ---------------------------------------------------------------------------------------------------------- |
| `pressed`  | `pressed`  | `boolean`                                                        | `false`       | Whether the toggle button is in the pressed state. Reflected as an attribute for CSS selectors.            |
| `variant`  | `variant`  | `'primary' \| 'secondary' \| 'tertiary' \| 'ghost' \| 'outline'` | `'secondary'` | Visual style variant of the button.                                                                        |
| `size`     | `hx-size`  | `'sm' \| 'md' \| 'lg'`                                           | `'md'`        | Size of the button.                                                                                        |
| `disabled` | `disabled` | `boolean`                                                        | `false`       | Prevents all interaction and form actions.                                                                 |
| `name`     | `name`     | `string \| undefined`                                            | `undefined`   | Form field name submitted via `ElementInternals` when the button is pressed.                               |
| `value`    | `value`    | `string \| undefined`                                            | `undefined`   | Form field value submitted via `ElementInternals` when the button is pressed.                              |
| `label`    | `label`    | `string \| undefined`                                            | `undefined`   | Accessible label forwarded to the inner `<button>` as `aria-label`. Required for icon-only toggle buttons. |
| `required` | `required` | `boolean`                                                        | `false`       | When true, the button must be in the pressed state for the form to be submitted.                           |

## Events

| Event       | Detail Type            | Description                                                             |
| ----------- | ---------------------- | ----------------------------------------------------------------------- |
| `hx-toggle` | `{ pressed: boolean }` | Dispatched when the toggle state changes. Not dispatched when disabled. |

## CSS Parts

| Part     | Description                         |
| -------- | ----------------------------------- |
| `button` | The native `<button>` element.      |

## Slots

| Slot        | Description                                |
| ----------- | ------------------------------------------ |
| _(default)_ | Button label text or content.              |
| `prefix`    | Icon or content rendered before the label. |
| `suffix`    | Icon or content rendered after the label.  |

## Form Integration

`hx-toggle-button` is fully form-associated via `ElementInternals`. When `pressed` is `true` and `value` is set, the value is submitted with the form. When not pressed, `null` is submitted.

```html
<form id="settings-form">
  <hx-toggle-button name="notifications" value="enabled" required>
    Enable Notifications
  </hx-toggle-button>
  <button type="submit">Save Settings</button>
</form>
```

## Accessibility

| Topic          | Details                                                                                                              |
| -------------- | -------------------------------------------------------------------------------------------------------------------- |
| ARIA role      | Inherits native `button` role.                                                                                       |
| `aria-pressed` | Set to `"true"` when pressed, `"false"` when unpressed. Always present so screen readers announce the toggle state.  |
| `aria-label`   | Set from the `label` property when provided. Required for icon-only toggle buttons where no visible text is present. |
| Keyboard       | `Tab` to focus; `Enter` / `Space` to toggle.                                                                         |
| Form           | Uses `ElementInternals` for form association. Supports `required` constraint validation.                             |
| WCAG           | Meets WCAG 2.1 AA (WCAG 4.1.2). A missing label emits a console warning during development.                          |

## Drupal Integration

```twig
{# my-module/templates/toggle-button.html.twig #}
<hx-toggle-button
  variant="{{ variant|default('secondary') }}"
  hx-size="{{ size|default('md') }}"
  {% if pressed %}pressed{% endif %}
  {% if disabled %}disabled{% endif %}
  {% if name %}name="{{ name }}"{% endif %}
  {% if value %}value="{{ value }}"{% endif %}
  {% if label %}label="{{ label }}"{% endif %}
>
  {{ content }}
</hx-toggle-button>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```

Listen for events in Drupal behaviors:

```javascript
Drupal.behaviors.helixToggleButton = {
  attach(context) {
    once('helixToggleButton', 'hx-toggle-button', context).forEach((el) => {
      el.addEventListener('hx-toggle', (e) => {
        console.log('Toggle state:', e.detail.pressed);
      });
    });
  },
};
```

      });
    </script>
  </body>
