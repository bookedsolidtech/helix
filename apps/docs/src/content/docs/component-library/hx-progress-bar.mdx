## Overview

`hx-progress-bar` is a horizontal linear progress indicator that communicates task completion or active loading states. It supports determinate progress (a known `value` between `min` and `max`), indeterminate progress (an animated state when duration is unknown), four semantic color variants, three track sizes, a visible label slot, and full `role="progressbar"` ARIA semantics.

The component announces completion to screen readers via `aria-live="polite"` and fires an `hx-complete` event when `value` reaches `max`.

**Use `hx-progress-bar` when:** you need to communicate a known percentage-complete or an active indeterminate loading state with a horizontal bar.

**Use `hx-spinner` instead when:** a compact circular indicator is more appropriate for the context (e.g., inline or overlay loading).

**Use `hx-progress-ring` instead when:** a circular arc indicator better suits the layout.

## Basic Usage

Minimal HTML snippet — no build tool required:

```html
<!-- Determinate progress -->
<hx-progress-bar value="60" label="Uploading document"></hx-progress-bar>

<!-- Indeterminate (unknown duration) -->
<hx-progress-bar indeterminate label="Loading patient records"></hx-progress-bar>

<!-- With visible label slot -->
<hx-progress-bar value="40">
  <span slot="label">Submitting prior authorization — 40%</span>
</hx-progress-bar>

<!-- Success variant on completion -->
<hx-progress-bar value="100" variant="success" label="Upload complete"></hx-progress-bar>
```

Control progress via JavaScript:

```javascript
const bar = document.querySelector('hx-progress-bar');

// Update progress
bar.value = 75;

// Switch to indeterminate
bar.indeterminate = true;

// Listen for completion
bar.addEventListener('hx-complete', () => {
  console.log('Progress complete!');
  bar.variant = 'success';
});
```

## Properties

| Property        | Attribute       | Type                                              | Default     | Description                                                                                                                                          |
| --------------- | --------------- | ------------------------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `value`         | `value`         | `number \| null`                                  | `null`      | Current progress value. Set to `null` for indeterminate state. Clamped to `[min, max]`. Reflects to attribute.                                       |
| `min`           | `min`           | `number`                                          | `0`         | Minimum progress value. Reflects to attribute.                                                                                                       |
| `max`           | `max`           | `number`                                          | `100`       | Maximum progress value. Reflects to attribute.                                                                                                       |
| `indeterminate` | `indeterminate` | `boolean`                                         | `false`     | When true, shows an animated indeterminate loading state regardless of `value`. Reflects to attribute.                                               |
| `label`         | `label`         | `string`                                          | `''`        | Accessible label for the progress bar (`aria-label`). Required when no `label` slot content is present. Omitting triggers a dev warning.             |
| `description`   | `description`   | `string`                                          | `''`        | Additional description linked via `aria-describedby`. Used for supplementary context beyond the primary label. Reflects to attribute.                |
| `size`          | `hx-size`       | `'sm' \| 'md' \| 'lg'`                            | `'md'`      | Track height. Maps to design size tokens. Reflects to attribute.                                                                                     |
| `variant`       | `variant`       | `'default' \| 'success' \| 'warning' \| 'danger'` | `'default'` | Visual color variant. Semantic variants include the variant name in `aria-valuetext` so state is not conveyed by color alone. Reflects to attribute. |

## Events

| Event         | Detail Type | Description                                                        |
| ------------- | ----------- | ------------------------------------------------------------------ |
| `hx-complete` | `void`      | Fired when `value` reaches `max`. `bubbles: true, composed: true`. |

```javascript
document.querySelector('hx-progress-bar').addEventListener('hx-complete', () => {
  console.log('Task complete!');
});
```

```css

  --hx-progress-bar-indicator-bg: #0077b6;

  --hx-progress-bar-indicator-bg: #059669;
  --hx-progress-bar-track-bg: #d1fae5;
}
```

## CSS Parts

| Part    | Description                                               |
| ------- | --------------------------------------------------------- |
| `track` | The outer track container element (`role="progressbar"`). |
| `fill`  | The filled portion of the track indicating progress.      |
| `label` | The label slot wrapper element.                           |

```css
/* Style the track container */
hx-progress-bar::part(track) {
  border-radius: 0;
}

/* Style the fill independently */

  background: linear-gradient(90deg, #0077b6, #00b4d8);
}
```

## Slots

| Slot    | Description                                                                                                                     |
| ------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `label` | Visible label text rendered above the progress bar track. When provided, it becomes the accessible label via `aria-labelledby`. |

## Accessibility

`hx-progress-bar` uses the native `role="progressbar"` pattern with complete ARIA range semantics. It meets WCAG 2.1 AA requirements including 1.4.1 (Use of Color), 4.1.2 (Name, Role, Value), and 1.4.3 (Contrast).

| Topic             | Details                                                                                                                                                                                  |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ARIA role         | `role="progressbar"` on the track element with `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, and `aria-valuetext`.                                                                  |
| `aria-label`      | Set from the `label` attribute when no visible label slot content is present. A dev warning is issued if neither is provided — unlabeled progress bars violate WCAG 4.1.2.               |
| `aria-labelledby` | Used instead of `aria-label` when the `label` slot contains visible text content, connecting the visible label to the progress bar.                                                      |
| `aria-valuetext`  | Provides human-readable progress text (e.g. `"60%"` or `"In progress"` for indeterminate). For semantic variants, includes the variant state: `"60% — Success"`. Satisfies WCAG 1.4.1.   |
| Completion        | An `aria-live="polite"` region announces `"Complete"` to screen readers when `value` reaches `max`.                                                                                      |
| Indeterminate     | When `indeterminate` is true or `value` is `null`, `aria-valuenow` is omitted and `aria-valuetext` is `"In progress"`.                                                                   |
| Color alone       | Semantic variants (`success`, `warning`, `danger`) include the variant name in `aria-valuetext` and a visually-hidden `<span>` — status is not conveyed by fill color alone. WCAG 1.4.1. |
| Reduced motion    | The indeterminate animation respects `prefers-reduced-motion: reduce`. A static partial fill is shown instead to indicate the loading state without motion.                              |
| WCAG              | Meets WCAG 2.1 AA. SC 1.4.1 (Use of Color), SC 4.1.2 (Name, Role, Value), SC 1.4.3 (Contrast). Zero axe-core violations across all variants and size combinations.                       |

## Drupal Integration

```twig
{# my-module/templates/my-template.html.twig #}
<hx-progress-bar
  {% if value is defined %}value="{{ value }}"{% endif %}
  {% if indeterminate %}indeterminate{% endif %}
  hx-size="{{ size|default('md') }}"
  variant="{{ variant|default('default') }}"
  label="{{ label|default('') }}"
  {% if description %}description="{{ description }}"{% endif %}
>
  {% if label_slot %}
    <span slot="label">{{ label_slot }}</span>
  {% endif %}
</hx-progress-bar>
```

Load the library in your module's `.libraries.yml`:

```yaml
helix-components:
  js:
    /libraries/helix/helix.min.js: { minified: true }
```

Listen for completion events in Drupal behaviors:

```javascript
Drupal.behaviors.helixProgressBar = {
  attach(context) {
    once('helixProgressBar', 'hx-progress-bar[data-hx-upload]', context).forEach((el) => {
      el.addEventListener('hx-complete', () => {
        el.variant = 'success';
        // Optionally hide after a delay
        setTimeout(() => el.setAttribute('hidden', ''), 2000);
      });
    });
  },
};
```

## Standalone HTML Example

Copy-paste this into a `.html` file and open it in a browser — no build tool needed:

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>hx-progress-bar example</title>
    <!-- @helixui/library is a private package — install via npm workspace, not CDN -->
    <!-- In your project: import '@helixui/library'; in your bundler entry point -->
  </head>
  <body
    style="font-family: sans-serif; padding: 2rem; display: flex; flex-direction: column; gap: 2rem; max-width: 600px;"
  >
    <!-- 1. Determinate upload progress -->
    <section>
      <hx-progress-bar id="upload-bar" value="0" variant="default">
        <span slot="label" id="upload-label">Uploading document — 0%</span>
      </hx-progress-bar>
      <div style="margin-top: 0.75rem; display: flex; gap: 0.5rem;">
        <button id="start-btn" style="padding: 0.375rem 0.75rem; cursor: pointer;">
          Start Upload
        </button>
        <button id="reset-btn" style="padding: 0.375rem 0.75rem; cursor: pointer;">Reset</button>
      </div>
    </section>

    <!-- 2. Indeterminate loading -->
    <section>
      <hx-progress-bar indeterminate label="Loading patient records"></hx-progress-bar>
    </section>

    <!-- 3. Clinical workflow steps -->
    <section>
      <div style="display: flex; flex-direction: column; gap: 0.75rem;">
        <hx-progress-bar value="100" variant="success">
          <span slot="label">Step 1: Patient verified</span>
        </hx-progress-bar>
        <hx-progress-bar value="100" variant="success">
          <span slot="label">Step 2: Insurance confirmed</span>
        </hx-progress-bar>
        <hx-progress-bar value="45" variant="default">
          <span slot="label">Step 3: Prior auth in progress — 45%</span>
        </hx-progress-bar>
        <hx-progress-bar value="0">
          <span slot="label">Step 4: Awaiting approval</span>
        </hx-progress-bar>
      </div>
    </section>

    <script>
      const bar = document.getElementById('upload-bar');
      const labelEl = document.getElementById('upload-label');
      let interval = null;

      document.getElementById('start-btn').addEventListener('click', () => {
        if (interval) return;
        bar.value = 0;
        bar.variant = 'default';

        interval = setInterval(() => {
          const newVal = (bar.value ?? 0) + 5;
          bar.value = newVal;
          labelEl.textContent = `Uploading document — ${newVal}%`;
          if (newVal >= 100) clearInterval(interval);
        }, 200);
      });

      bar.addEventListener('hx-complete', () => {
        interval = null;
        bar.variant = 'success';
        labelEl.textContent = 'Upload complete!';
      });

      document.getElementById('reset-btn').addEventListener('click', () => {
        clearInterval(interval);
        interval = null;
        bar.value = 0;
        bar.variant = 'default';
        labelEl.textContent = 'Uploading document — 0%';
      });
    </script>
  </body>
</html>
```
