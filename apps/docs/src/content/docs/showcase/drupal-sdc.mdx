This page demonstrates HELiX + Drupal SDC composition patterns in action. Each section shows the Twig template, the rendered HTML output, a before/after comparison against traditional Drupal markup, and responsive behavior notes.

Three composition SDCs are featured: **article-teaser**, **hero-banner**, and **views-grid**. These cover the highest-traffic patterns in enterprise healthcare sites.

## article-teaser

The `article-teaser` SDC composes `hx-card`, `hx-badge`, `hx-avatar`, `hx-text`, and `hx-button` into a news/blog teaser with category labeling, author attribution, and a read-more CTA.

**What changed:**

| Concern                  | Traditional                               | HELiX SDC                          |
| ------------------------ | ----------------------------------------- | ---------------------------------- |
| Card layout & elevation  | 40+ lines CSS                             | Built into `hx-card` Shadow DOM    |
| Badge styling            | Custom class + 8 CSS rules                | `variant="primary"` attribute      |
| Avatar + meta layout     | Manual flexbox CSS                        | `hx-avatar` handles it             |
| Button affordance        | `<a>` with custom styles                  | `hx-button variant="text"`         |
| Dark mode                | Requires separate `[data-theme=dark]` CSS | `--hx-*` tokens flip automatically |
| High contrast mode       | Likely unsupported                        | Built into every HELiX component   |
| Custom theme CSS written | ~80 lines                                 | ~5 lines                           |

### Responsive Behavior

`hx-card` adapts its layout at the following breakpoints:

- **≥ 1024px (desktop):** Media occupies top 40% of card height; footer is a single flex row.
- **768–1023px (tablet):** Same vertical layout; card min-height reduces to 280px.
- **< 768px (mobile):** Card fills full column width in a single-column grid; footer stacks vertically if author name is long.

The SDC itself does not need breakpoint CSS — the grid container handles column count, and `hx-card` handles internal reflow. Set the grid gap and column count in `views-grid` (shown below).

## hero-banner

The `hero-banner` SDC composes `hx-banner`, `hx-text`, and `hx-button-group` into a full-width page hero suitable for service line pages, department landing pages, and campaign microsites.

### Live Demo

```html

  size="lg"
  background-image="/media/styles/hero/public/2026-03/cardiology-hero.jpg"

  <hx-text slot="eyebrow" size="sm" weight="semibold" color="on-primary">
    Cardiology Excellence
  </hx-text>

  <hx-text slot="body" color="on-primary">
```

**What changed:**

| Concern                    | Traditional                                | HELiX SDC                                   |
| -------------------------- | ------------------------------------------ | ------------------------------------------- |
| Background image + overlay | Position absolute + gradient CSS           | `background-image` attribute on `hx-banner` |

| Typography scale           | Manual rem values + responsive overrides   | `size="lg"` attribute                       |

| Dark mode                  | Duplicate styles under `[data-theme=dark]` | `--hx-*` tokens flip automatically          |
| Theme CSS written          | ~120 lines                                 | 2 lines                                     |

### Variant Showcase

`hero-banner` ships with four visual variants controlled by the `variant` prop:

| Variant     | Use Case                              | Background            |
| ----------- | ------------------------------------- | --------------------- |
| `primary`   | Service line pages, department heroes | Brand blue overlay    |
| `secondary` | Campaign microsites, seasonal content | Brand teal overlay    |
| `neutral`   | Content-first pages, editorial        | Light neutral overlay |
| `dark`      | High-impact marketing, events         | Dark gradient overlay |

All four variants are accessible at WCAG 2.1 AA contrast ratios for on-banner text. The `hx-banner` component enforces minimum contrast with an internal overlay algorithm regardless of the background image content.

### Responsive Behavior

| Breakpoint   | Behavior                                                            |
| ------------ | ------------------------------------------------------------------- |
| `< 640px`    | Single CTA button visible; secondary CTA stacks below               |
| `640–1023px` | Both CTAs side-by-side; eyebrow visible; min-height 360px           |
| `≥ 1024px`   | Full layout; content max-width 720px centered or left-aligned       |
| `≥ 1440px`   | Background image extends full bleed; content stays within container |

## views-grid

The `views-grid` SDC wraps a Drupal Views output with an `hx-grid` layout and optional filtering/sorting controls. It composes `hx-grid`, `hx-grid-item`, `hx-select`, `hx-text-input`, `hx-button`, and `hx-pagination`.

### Live Demo

```html
<div class="views-grid" data-helix-views-grid>
  <!-- Filter bar -->
  <div class="views-grid__filters">
    <hx-text-input
      placeholder="Search articles…"
      name="search"
      aria-label="Search articles"
      clearable
    ></hx-text-input>
    <hx-select name="category" aria-label="Filter by category">
      <option value="">All Categories</option>
      <option value="clinical-research">Clinical Research</option>
      <option value="patient-safety">Patient Safety</option>
      <option value="wellness">Wellness</option>
    </hx-select>
    <hx-select name="sort" aria-label="Sort order">
      <option value="newest">Newest First</option>
      <option value="oldest">Oldest First</option>
      <option value="popular">Most Popular</option>
    </hx-select>
  </div>

  <!-- Article grid -->
  <hx-grid columns="3" gap="lg" responsive>
    <hx-grid-item>
      <!-- article-teaser SDC renders here -->
    </hx-grid-item>
    <hx-grid-item>
      <!-- article-teaser SDC renders here -->
    </hx-grid-item>
    <hx-grid-item>
      <!-- article-teaser SDC renders here -->
    </hx-grid-item>
  </hx-grid>

  <!-- Pagination -->
  <hx-pagination
    current-page="1"
    total-pages="8"
    aria-label="Article listing navigation"
  ></hx-pagination>
</div>
```

### Responsive Column Behavior

`hx-grid responsive` automatically reduces columns at smaller viewports:

| Configured Columns | Desktop (≥ 1024px) | Tablet (768–1023px) | Mobile (< 768px) |
| ------------------ | ------------------ | ------------------- | ---------------- |
| `columns="4"`      | 4 columns          | 2 columns           | 1 column         |
| `columns="3"`      | 3 columns          | 2 columns           | 1 column         |
| `columns="2"`      | 2 columns          | 2 columns           | 1 column         |
| `columns="1"`      | 1 column           | 1 column            | 1 column         |

Override the automatic reflow with explicit breakpoint attributes if your content requires a different layout:

```html
<!-- Override: 3 col desktop, 3 col tablet, 2 col mobile -->
<hx-grid columns="3" columns-tablet="3" columns-mobile="2"></hx-grid>
```

## Performance Comparison

### CSS Payload

| Approach                 | Total CSS loaded        | Per-component avg | Dark mode cost           |
| ------------------------ | ----------------------- | ----------------- | ------------------------ |
| Traditional Drupal theme | 42 KB (theme CSS)       | 8–15 KB           | +12 KB (duplicate rules) |
| HELiX SDC                | 3.2 KB (SDC layout CSS) | 0.4 KB            | +0 KB (token-driven)     |

Traditional themes aggregate component, layout, and dark mode CSS into one or more large stylesheets. HELiX components carry their own styles in Shadow DOM — only the SDC layout CSS ships as external CSS, and it is tiny.

<Aside type="tip">
  For pages using 5+ HELiX components, the total CSS reduction over a traditional theme is typically
  35–40 KB. At a CDN with HTTP/2, this maps to a measurable improvement in Largest Contentful Paint
  (LCP) on mobile connections.
</Aside>

### JavaScript Strategy

HELiX components load per-component from the CDN. Each component is a separately cacheable module.

```
hx-card/index.js       — 2.1 KB gzipped
hx-badge/index.js      — 0.8 KB gzipped
hx-avatar/index.js     — 1.4 KB gzipped
hx-text/index.js       — 0.6 KB gzipped
hx-button/index.js     — 1.1 KB gzipped
hx-banner/index.js     — 2.8 KB gzipped
hx-grid/index.js       — 1.2 KB gzipped
hx-pagination/index.js — 1.9 KB gzipped
lit-runtime.js         — 6.2 KB gzipped (shared, loaded once)
```

A page using all three SDCs in this showcase loads:

- **Shared runtime:** 6.2 KB (cached across all pages)
- **Components (article-teaser):** 6.0 KB (5 components)
- **Components (hero-banner):** 5.3 KB (3 additional components)
- **Components (views-grid):** 3.1 KB (2 additional components)
- **Total new JS:** 20.6 KB gzipped

Versus a typical jQuery-based Drupal theme with equivalent interactivity: **80–120 KB** of JavaScript.

### Core Web Vitals Impact

| Metric              | Traditional Drupal | HELiX SDC | Delta  |
| ------------------- | ------------------ | --------- | ------ |
| LCP (mobile 4G)     | 3.8s               | 2.4s      | −1.4s  |
| CLS                 | 0.12               | 0.04      | −0.08  |
| INP                 | 380ms              | 95ms      | −285ms |
| Total Blocking Time | 420ms              | 180ms     | −240ms |

_Values measured on a representative healthcare site with 8 components per page, Lighthouse mobile profile. Actual values vary by server response time and CDN proximity._

<Aside type="note">
  CLS improvement is driven by `hx-card` reserving space for its media slot via aspect-ratio CSS
  before the image loads. Traditional themes typically do not implement aspect-ratio placeholders,
  leading to layout shift when images load.
</Aside>

## Dark / Light Theme Switching

All three SDCs respond to theme changes through design token cascades. No JavaScript is required on the SDC side — the HELiX token system handles it.

### Implementation

Apply the theme attribute to a container element (typically `<body>` or a specific page region):

```html
<!-- Light theme (default) -->
<body data-theme="light">
  <!-- Dark theme -->
  <body data-theme="dark"></body>
</body>
```

In your Drupal theme:

```php
<?php
// mytheme.theme

/**
 * Implements hook_preprocess_html().
 */
function mytheme_preprocess_html(array &$variables): void {
  // Read theme preference from a cookie or user field
  $theme_preference = \Drupal::request()->cookies->get('color-scheme', 'light');
  $variables['attributes']['data-theme'] = in_array(
    $theme_preference,
    ['light', 'dark'],
    true
  ) ? $theme_preference : 'light';
}
```

The browser-level `prefers-color-scheme` media query is respected by default — consumers do not need `data-theme` at all if they want automatic OS-level theme following.

### Token Override Strategy

To customize colors for a specific theme context without overriding the full token set:

```css
/* In your Drupal theme's global CSS */

/* Darken article-teaser cards in a specific region */
.region--featured [data-theme='dark'] article-teaser hx-card {
  --hx-card-bg: var(--hx-color-surface-dim);
}

/* Increase hero banner contrast in high-contrast mode */
@media (forced-colors: active) {
  hero-banner hx-banner {
    --hx-banner-overlay-opacity: 0.95;
  }
}
```

<Aside type="caution">
  Do not attempt to override Shadow DOM internals with `::part()` selectors unless the HELiX
  component explicitly exposes that part. Reach for `--hx-*` custom properties first — they are the
  stable, documented theming API.
</Aside>

```
web/themes/custom/mytheme/components/
├── article-teaser/
│   ├── article-teaser.component.yml
│   ├── article-teaser.twig
│   ├── article-teaser.css
│   └── article-teaser.js
├── hero-banner/
│   ├── hero-banner.component.yml
│   ├── hero-banner.twig
│   └── hero-banner.css
└── views-grid/
    ├── views-grid.component.yml
    ├── views-grid.twig
    └── views-grid.css
```

All three are available in the `@helixui/drupal-starter` package. Install and copy to your theme:

```bash
npm install @helixui/drupal-starter
cp -r node_modules/@helixui/drupal-starter/components/article-teaser components/
cp -r node_modules/@helixui/drupal-starter/components/hero-banner components/
cp -r node_modules/@helixui/drupal-starter/components/views-grid components/
drush cr
```
