<h3 style={{ marginTop: 32 }}>Buttons & toggles</h3>

  <code>hx-button</code> and <code>hx-icon-button</code> wrap a real native{' '}
  <code>&lt;button&gt;</code>
  in their shadow root — keyboard activation (Space / Enter) is handled by the user agent.
  <code>hx-switch</code> and <code>hx-checkbox</code> implement an APG-style host keydown contract

</p>

  rows={[
    ['Tab', 'Focus the control'],
    ['Space', 'Activate / toggle'],

<h3 style={{ marginTop: 32 }}>Single-select listbox</h3>
<p className="hx-docs-card-body">
  <code>hx-select</code> (closed combobox + open listbox), <code>hx-radio-group</code>. Roving
  tabindex inside the group; arrow keys move within, Tab leaves.
</p>
<KeyTable
  rows={[

  ]}

<h3 style={{ marginTop: 32 }}>Tabs</h3>
<p className="hx-docs-card-body">

</p>
<KeyTable

<section>
  <SectionHead title="What we never do" meta="anti-patterns" />
  <ul style={{ fontSize: 14, lineHeight: 1.7, paddingLeft: 20 }}>
    <li>
      <strong>Trap Tab inside a non-modal widget.</strong> Tab must always leave any non-modal
      group; only modal dialogs trap. WCAG 2.1.2.
    </li>
    <li>
      <strong>Reinvent Enter / Space.</strong> The activation key for a button is Space (canonical)
      and Enter (form-submit semantics). Both must work.
    </li>
    <li>
      <strong>Hide focus.</strong> No <code>outline: none</code> without a visible replacement —
      ever. SC 2.4.7.
    </li>
    <li>
      <strong>Mouse-only state.</strong> Hover-only menus, drag-only reordering — every gesture has
      a keyboard equivalent.
    </li>
    <li>
      <strong>Single-character shortcuts that aren't remappable.</strong> SC 2.1.4 requires a way to
      turn off, remap, or activate-only-on-focus.
    </li>
  </ul>
</section>
