## Live state demos

<SectionHead title="Focus visible" meta="2.4.13 Focus Appearance" />

The focus ring is a 2px solid outline rendered on the inner `<button>` part with a contrast ratio ≥3:1 against both the focused and unfocused background. Tab to the button below to see the indicator.

<div style={{ padding: '1rem 0' }}>
  <hx-button variant="primary">Tab to focus me</hx-button>
</div>

<SectionHead title="Disabled state" meta="2.1.3 + APG button.disabledSuppresses" />

A disabled button suppresses both pointer activation AND keyboard activation (`Enter` / `Space`). The `hx-click` event does not fire. Disabled appearance uses reduced opacity, but the contrast ratio is still preserved through the focus path because the underlying `<button>` retains its accessible name.

<div style={{ padding: '1rem 0' }}>
  <hx-button variant="primary" disabled>
    Disabled — no activation
  </hx-button>
</div>

<SectionHead title="Loading state" meta="3.2.5 Change on Request" />

Loading state shows an inline spinner and prevents double-click submission. The button remains in DOM flow with stable dimensions (no layout shift), and the accessible name is preserved so the announcement remains stable for screen readers during the in-flight state.

<div style={{ padding: '1rem 0' }}>
  <hx-button variant="primary" loading>
    Submitting referral…
  </hx-button>
</div>

<SectionHead title="Danger variant" meta="1.4.6 Contrast (Enhanced)" />

The danger variant uses `--hx-color-danger-500` against `text.on-danger` (white) — the contrast ratio clears 7:1 (AAA) on every shipping brand (Apex, Meridian, Lumen, Verdant, Signal, Ember). Use sparingly and pair with confirmation flows for destructive operations.

<div style={{ padding: '1rem 0' }}>
  <hx-button variant="danger">Delete patient record</hx-button>
</div>
