# HX Tbody

Semantic table body section. Must be a direct child of `hx-table`.
Contains `hx-tr` rows with `hx-td` data cells.

## Usage

```twig
{% include 'helix:hx-tbody' with {
} %}
```

## Slots

| Slot | Description |
|------|-------------|
| (default) | Default slot for `hx-tr` elements. |

## CSS Parts

| Part | Description |
|------|-------------|
| tbody | The `<tbody>` element. |
