# HX Thead

Semantic table head section. Must be a direct child of `hx-table`.
Contains `hx-tr` rows with `hx-th` header cells.

## Usage

```twig
{% include 'helix:hx-thead' with {
} %}
```

## Slots

| Slot | Description |
|------|-------------|
| (default) | Default slot for `hx-tr` elements. |

## CSS Parts

| Part | Description |
|------|-------------|
| thead | The `<thead>` element. |
