# HX Tfoot

Semantic table foot section. Must be a direct child of `hx-table`.
Typically contains summary or totals rows.

## Usage

```twig
{% include 'helix:hx-tfoot' with {
} %}
```

## Slots

| Slot | Description |
|------|-------------|
| (default) | Default slot for `hx-tr` elements. |

## CSS Parts

| Part | Description |
|------|-------------|
| tfoot | The `<tfoot>` element. |
