# Release Manifests

Each HELiX release produces a JSON manifest in this directory that captures the ground truth of what was shipped: source commit, CI run, changeset files consumed, merged PRs since the prior tag, CEM hash, and the npm publish actor. Manifests are generated by [`scripts/generate-release-manifest.mjs`](../../scripts/generate-release-manifest.mjs) during the `publish.yml` workflow and committed alongside the version-bump PR that `changesets/action` opens.

## GitHub Environment `npm-publish`

`.github/workflows/publish.yml` gates the `publish` job on a GitHub Environment named `npm-publish`. This is a human-in-the-loop approval point — the workflow pauses until a required reviewer clicks **Approve and deploy** on the run page.

**Configuration (one-time):**

1. GitHub repo → **Settings** → **Environments** → **New environment**
2. Name: `npm-publish`
3. **Protection rules** → **Required reviewers** → add `jake` (or `@himerus`). Leave other reviewers off.
4. **Wait timer**: `0` — the gate is a reviewer click, not a delay.
5. **Deployment branches**: restrict to `main` only.

Until the environment is configured, the `publish` job fails at queue time with an *"environment does not exist"* error. The `secret-scan` job runs first and is not environment-gated.

```jsonc
{
  "tag": "@helixui/library@3.0.0",
  "commit_sha": "...",
  "ref": "refs/heads/main",
  "repository": "bookedsolidtech/helix",
  "published_at": "2026-04-18T22:00:00.000Z",
  "publisher": "himerus",
  "ci_run_id": "123456789",
  "ci_run_url": "https://github.com/bookedsolidtech/helix/actions/runs/123456789",
  "packages": {
    "@helixui/library": "3.0.0",
    "@helixui/tokens": "3.0.0",
    "@helixui/react": "3.0.0"
  },
  "changeset_files": ["3.0.0-breaking.md", ...],
  "merged_prs_since_last_tag": [1475, 1478, ...],
  "last_tag": "@helixui/library@2.1.2",
  "cem_sha256": "...",
  "cdn_budget_snapshot": { ... },
  "coderabbit_final_review_sha": null,
  "notes": "..."
}
```

## Post-release checklist

After a tag ships:

- [ ] Manifest committed to `docs/releases/<version>-manifest.json` via the version-bump PR.
- [ ] `npm view @helixui/library@<version>` returns the new version.
- [ ] Discord `#releases` announcement with release-notes link.
- [ ] CHANGELOG.md in `packages/hx-library/` reflects the tag.
- [ ] Starlight docs site rebuilt with new CEM.
